- **MC-P01 · X is not complete until Y.** — 直到 Y，X 才算完成；用法：until 后接从句；不要把 not ... until 误读成“在此之前已经完成”；例句：The review is not complete until every citation has been checked. [来源](https://github.com/MengJingsong/Misconfiguration/blob/7348bdb964b315ea2e2963e3f1523d17e080897e/cassandra/if-check-exp/README.md#L16)
- **MC-P02 · If X ..., Y ...; otherwise, Z ... .** — 如果满足条件，采取 Y；否则采取 Z；用法：说明两条分支；otherwise 后通常是完整分句；例句：If capacity is available, the task proceeds; otherwise, it waits. [来源](https://github.com/MengJingsong/Misconfiguration/blob/7348bdb964b315ea2e2963e3f1523d17e080897e/cassandra/if-check-exp/stage3-ai-deep-read/cases/memtable_heap_space-tryAllocate-limit.md#L43)
- **MC-P03 · X remains ... unless Y ... .** — 除非 Y，否则 X 仍然……；用法：unless = if ... not；一般不再加 not；例句：The task remains blocked unless another worker releases capacity. [来源](https://github.com/MengJingsong/Misconfiguration/blob/7348bdb964b315ea2e2963e3f1523d17e080897e/cassandra/entry-restriction-exp/memtable_heap_space/memtable_heap_space-02-summary.md#L22)
- **MC-P04 · Before doing X, check whether Y.** — 在做 X 之前，先确认 Y 是否成立；用法：before + 动名词；whether 引导待确认的问题；例句：Before interpreting the graph, check whether the limit was reached. [来源](https://github.com/MengJingsong/Misconfiguration/blob/7348bdb964b315ea2e2963e3f1523d17e080897e/cassandra/if-check-exp/stage3-ai-deep-read/_TEMPLATE.md#L252)
- **MC-P05 · By the time X happens, Y has already happened.** — 等到 X 时，Y 已经发生；用法：描述已先行完成的动作；过去叙述用 happened / had happened；例句：By the time the counter is updated, the allocation has already happened. [来源](https://github.com/MengJingsong/Misconfiguration/blob/7348bdb964b315ea2e2963e3f1523d17e080897e/cassandra/if-check-exp/stage3-ai-deep-read/cases/column_index_cache_size-indexSamples-cacheSizeThreshold.md#L178)
- **MC-P06 · Because X ..., Y ... .** — 因为 X，所以 Y；用法：英语通常不用 because ... so ... 双连词；例句：Because the source has changed, the old line numbers may be wrong. [来源](https://github.com/MengJingsong/Misconfiguration/blob/7348bdb964b315ea2e2963e3f1523d17e080897e/cassandra/if-check-exp/stage2-ai-preprocessing/bands.md#L2)
- **MC-P07 · X ..., which means that Y ... .** — X，而这意味着 Y；用法：which 指前面的情况；适合解释含义或后果；例句：The setting is read only at startup, which means that a restart is required. [来源](https://github.com/MengJingsong/Misconfiguration/blob/7348bdb964b315ea2e2963e3f1523d17e080897e/cassandra/if-check-exp/stage3-ai-deep-read/cases/max_hints_size_per_host-shouldHint-maxHintsSize.md#L73)
- **MC-P08 · X ..., so that Y can ... .** — X，以便 Y 能……；用法：so that 强调目的；源文 so every file is self-contained 的教学改写；例句：Record the assumptions so that another researcher can repeat the test. [来源](https://github.com/MengJingsong/Misconfiguration/blob/7348bdb964b315ea2e2963e3f1523d17e080897e/cassandra/entry-restriction-exp/README.md#L83)
- **MC-P09 · X depends on both A and B.** — X 同时取决于 A 和 B；用法：both A and B 两项结构平行；例句：Queue growth depends on both the arrival rate and the processing rate. [来源](https://github.com/MengJingsong/Misconfiguration/blob/7348bdb964b315ea2e2963e3f1523d17e080897e/cassandra/entry-restriction-exp/memtable_flush_writers/memtable_flush_writers-02-summary.md#L51)
- **MC-P10 · The more X ..., the more Y ... .** — X 越……，Y 越……；用法：两边都用 the + 比较级；此句式是对源文因果关系的教学改写；例句：The longer the consumer falls behind, the more data accumulates. [来源](https://github.com/MengJingsong/Misconfiguration/blob/7348bdb964b315ea2e2963e3f1523d17e080897e/cassandra/if-check-exp/stage3-ai-deep-read/cases/cdc_total_space-processNewSegment-allowance.md#L96)
- **MC-P11 · X may ..., but that does not mean Y ... .** — X 可能……，但不能由此断定 Y；用法：用于限制结论，避免过度推断；源文关系的教学改写；例句：The counter may stay below the limit, but that does not mean total memory is bounded. [来源](https://github.com/MengJingsong/Misconfiguration/blob/7348bdb964b315ea2e2963e3f1523d17e080897e/cassandra/if-check-exp/stage3-ai-deep-read/cases/file_cache_size-allocateMoreChunks-memoryUsageThreshold.md#L223)
- **MC-P12 · X is consistent with Y, but does not establish Y.** — X 与 Y 一致，但不足以证明 Y（复习拓展）；用法：consistent with 比 proves 弱；源文证据区分的教学改写；例句：The trend is consistent with the hypothesis, but does not establish it. [来源](https://github.com/MengJingsong/Misconfiguration/blob/7348bdb964b315ea2e2963e3f1523d17e080897e/cassandra/if-check-exp/stage3-ai-deep-read/cases/column_index_cache_size-indexSamples-cacheSizeThreshold.md#L323)
- **MC-P13 · X alone is not proof, because Y could also ... .** — 单凭 X 不能证明，因为 Y 也可能……（复习拓展）；用法：明确给出替代解释；源文证据要求的教学改写；例句：A lower memory peak alone is not proof, because a slower workload could also produce it. [来源](https://github.com/MengJingsong/Misconfiguration/blob/7348bdb964b315ea2e2963e3f1523d17e080897e/cassandra/if-check-exp/stage3-ai-deep-read/_TEMPLATE.md#L195)
- **MC-P14 · To distinguish A from B, measure C.** — 为了区分 A 和 B，测量 C；用法：distinguish A from B；不是 distinguish A with B；例句：To distinguish blocking from rejection, measure whether the request later completes. [来源](https://github.com/MengJingsong/Misconfiguration/blob/7348bdb964b315ea2e2963e3f1523d17e080897e/cassandra/if-check-exp/stage3-ai-deep-read/cases/file_cache_size-allocateMoreChunks-memoryUsageThreshold.md#L203)
- **MC-P15 · X is refuted if Y ... .** — 如果观察到 Y，X 就被证伪；用法：写可观察的反例；缺乏证据不自动等于 refuted；例句：The claim is refuted if valid measurements exceed the predicted bound. [来源](https://github.com/MengJingsong/Misconfiguration/blob/7348bdb964b315ea2e2963e3f1523d17e080897e/cassandra/if-check-exp/stage3-ai-deep-read/cases/MAX_HINT_BUFFERS-switchCurrentBuffer-MAX_ALLOCATED_BUFFERS.md#L245)
- **MC-P16 · Without X, we cannot tell whether A or B.** — 没有 X，就无法判断是 A 还是 B（复习拓展）；用法：whether A or B 两项保持平行；源文解释混淆的教学改写；例句：Without a branch signal, we cannot tell whether the task was blocked or merely slow. [来源](https://github.com/MengJingsong/Misconfiguration/blob/7348bdb964b315ea2e2963e3f1523d17e080897e/cassandra/if-check-exp/stage3-ai-deep-read/_TEMPLATE.md#L199)
- **MC-P17 · Hold A fixed while varying B.** — 保持 A 不变，同时改变 B；用法：实验写作常用；vary 作及物动词；例句：Hold the workload fixed while varying the memory limit. [来源](https://github.com/MengJingsong/Misconfiguration/blob/7348bdb964b315ea2e2963e3f1523d17e080897e/cassandra/if-check-exp/stage4-runtime-verification/_TEMPLATE.md#L79)
- **MC-P18 · X was observed; Y was inferred from Z.** — X 是观察所得；Y 是从 Z 推断所得；用法：明确区分实测和推断；源文 observed / inferred 标签的教学改写；例句：The timeout was observed; blocking was inferred from the test design. [来源](https://github.com/MengJingsong/Misconfiguration/blob/7348bdb964b315ea2e2963e3f1523d17e080897e/cassandra/if-check-exp/stage4-runtime-verification/results/memtable_heap_space-tryAllocate-limit.md#L89)
- **MC-P19 · The result applies to X; it does not establish Y.** — 结果适用于 X；不能据此证明 Y；用法：限制外推范围；源文测试层级区分的教学改写；例句：The result applies to this unit test; it does not establish behavior under cluster load. [来源](https://github.com/MengJingsong/Misconfiguration/blob/7348bdb964b315ea2e2963e3f1523d17e080897e/cassandra/if-check-exp/stage4-runtime-verification/results/memtable_heap_space-tryAllocate-limit.md#L4)
- **MC-P20 · X differs from Y in that ... .** — X 与 Y 的区别在于……；用法：in that 后接完整从句；源文比较关系的教学改写；例句：This check differs from the other one in that it runs before the task starts. - **MC-P22 · X is bounded by A, not by B.** — X 受 A 限制，而非 B；用法：用于精准界定限制的对象或依据；例句：The pool is bounded by its capacity, not by the number of requests received.
