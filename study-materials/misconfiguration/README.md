# Misconfiguration — English study module

基于 Misconfiguration 仓库的技术说明、实验分析和交接记录，练习科研与工作交流中的英语。共 **60 个词汇、48 个短语与搭配、24 个句式**，另有 12 条用法辨析、4 段听力材料和 12 项练习。

## Files

- [Vocabulary](vocabulary.md)：词性、中文含义、常用搭配和例句。
- [Phrases and collocations](phrases.md)：介词、固定搭配、短语动词和工作表达。
- [Sentence patterns](patterns.md)：条件、因果、比较、证据强度和范围限定。
- [Usage notes](usage-notes.md)：易混词与常见错误；引用前面条目的编号。
- [Practice](practice.md)：听力、主动回忆、口语、写作和延迟迁移。
- [Suggested answers](answers.md)：完成练习后再打开。
- [Source inventory](sources.md)：本次读取的全部 53 个 Markdown 文件及固定版本链接。

## How to study

先学 vocabulary 的 MC-V01–MC-V29 和 phrases 的常用表达，再学证据与研究方法词汇及 patterns。每次选择约 8–12 项，先理解例句，再遮住英文尝试表达，最后换场景复用。这里的顺序只是入门建议；正式复习仍按 [English Study instructions](../../english-study/README.md) 和 [mastery state](../../english-study/mastery.md) 选择内容。

说“听力训练”时，只输出选中的英文段落正文。不要输出编号、标题、解释、中文或来源链接。说“测试”时，先隐藏答案和目标表达；完成有意义的测试后，才按既有规则更新学习记录。
