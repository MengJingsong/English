# Session Instruction Router

Use `/english-study/README.md` for repository-wide rules.

Load the task-specific instruction file that matches the current session:

- quoted Chinese/English lookup → `lookup.md`
- learning new material → `study.md`
- “复习” → `review.md`
- “测试” → `test.md`
- “听力训练” → `listening.md`
- “整理 inbox” → `curate-inbox.md`

If multiple modes apply, use the smallest set needed for the current request.

Unquoted English input should normally be proofread and rephrased naturally unless the user asks for another task.
